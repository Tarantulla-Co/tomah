# Tomah International storefront

Public marketing, retail and wholesale storefront for Tomah International. It is a pure client of the separate `tomah-admin` public API and defaults to a complete local mock.

```bash
cp .env.example .env.local
npm install
npm run dev
```

See [docs/storefront-handover.md](docs/storefront-handover.md) for the endpoint contract, environment, payment callback, build facts and open integration questions.
